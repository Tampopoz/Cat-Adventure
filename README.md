## Project Structure

```text
Assets/        Game assets
Scenes/        Game scenes
Scripts/       Game scripts
Sound/         Sound files
project.godot  Godot project file
```

## How to Run

1. Download or clone this repository.
2. Open Godot Engine.
3. Click Import.
4. Select the `project.godot` file.
5. Open the project and press Run.
